# 💎 Radium Boutique — 2027 Shopping Experience

A premium, ultra-modern, and avant-garde front-end concepts design for an exclusive urban fashion boutique. This project rewrites the rules of web interaction by combining dark minimalist aesthetics with high-performance scroll-driven animations.

## ✨ Features

- **2027 Kinetic UI Architecture:** Sleek, futuristic interface featuring advanced glassmorphism and modern dark-mode layouts.
- **Advanced GSAP Parallax & Animations:** Powered by GSAP and ScrollTrigger for butter-smooth interactive scrolling experiences.
- **Bento Grid Navigation:** Apple-inspired responsive layout organization for showcase metrics and category highlights.
- **Pure Responsive Engineering:** Engineered to deliver flawless visual presentation and interactive fidelity across all viewports.
- **Micro-interactions:** Glowing hover effects, smooth transitions, and dynamic absolute-positioned overlay actions on interactive elements.

## 🛠️ Tech Stack

- **Markup:** Semantic HTML5
- **Styling:** Custom CSS3 with advanced variables, flexbox, and grid systems
- **Animations:** GSAP (GreenSock Animation Platform) & ScrollTrigger plugin
- **Icons:** Font Awesome 6.4.0

## 📁 Project Structure

```text
├── index.html       # Primary structural layouts
├── style.css        # Core design systems and responsive definitions
├── app.js           # GSAP timelines and event orchestration
└── README.md        # Documentation
```
